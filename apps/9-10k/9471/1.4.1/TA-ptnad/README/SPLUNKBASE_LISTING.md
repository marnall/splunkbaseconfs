## Short description

Official Positive Technologies add-on for parsing, normalizing, searching, and
visualizing PT NAD syslog events in Splunk.

## Detailed description

The Official PT NAD Technology Add-on for Splunk provides field extraction,
normalization, CIM event typing and tagging, historical event parsing, and security dashboards
for RFC 5424-compatible syslog events generated by Positive Technologies
Network Attack Discovery. It supports attack alerts, activity detections,
indicators of compromise, audit events, and combined multi-rule incidents. The
included dashboard provides attack, host, application protocol, MITRE ATT&CK,
IOC, and audit visibility. CIM mappings cover Intrusion Detection, Alerts,
Authentication, and Change data models. Correlation content remains under the
customer Detection Engineer's control.
