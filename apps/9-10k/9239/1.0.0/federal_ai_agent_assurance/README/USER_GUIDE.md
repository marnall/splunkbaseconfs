# User Guide

Developers: Register your agent (Agent Registry). Author a manifest —
start from samples/sample_manifest_v1.json — create the release (Release
Workbench), attach TEVV evidence (TEVV view: save the suite, paste
transcripts, evaluate), run Evaluate policies, fix findings, Submit, then
Record tests. You cannot review or authorize your own release.

Reviewers: open the release, use Diff and Findings (authority expansions
first), optionally run AI advisory modules, then Independent review or
Request changes with comments. Waivers: Review and Risk view.

Authorizing officials: Accept risk with a statement, then Authorize —
conditions, boundary, and expiration are recorded and sealed. Suspend/
revoke from the same panel when needed.

Operations: import observations in Runtime Attestation; DRIFT flags the
release for reassessment. Export/verify evidence in Evidence and
Transfers.
