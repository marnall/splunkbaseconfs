# Release Notes

First release of Federal AI Agent Assurance (AssuranceOps suite):
agent registry; canonical sealed Agent Release Manifests (schema 1.0);
deterministic semantic diff with authority-expansion detection and stable
evidence IDs; closed-DSL policy engine + read-only Federal Agent Release
Baseline (25 policies); versioned TEVV suites, offline transcript format,
deterministic evaluator; server-enforced lifecycle with strict separation
of duties, waivers, stale-revision/lock/idempotency protection;
SHA-256-sealed authorization decisions with expiration, supersession,
suspension, revocation; runtime attestation with
CONFORMANT/DRIFT/UNKNOWN/NOT_ATTESTABLE semantics; optional read-only
LookupOps dependency evidence import + drift propagation; object-scoped
hash-chained audit with verification endpoint; deterministic hash-verified
evidence bundles; optional zero-authority behind-the-firewall AI review;
11 Simple XML views; labeled sample content; full documentation set.
