MISPFuse privacy statement

MISPFuse sends no telemetry, analytics, diagnostics, advertising data, or
configuration data to the publisher. It sends only the Splunk result fields
selected by the active mapping template to the MISP server configured by the
administrator. MISP API keys and proxy passwords use Splunk's encrypted
credential storage.

Splunk may check Splunkbase for app updates because the app enables Splunk's
standard update check. MISPFuse does not implement a separate update or
telemetry service.
