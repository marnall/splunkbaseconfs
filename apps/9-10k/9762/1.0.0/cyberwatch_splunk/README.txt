Cyberwatch

Dashboards for the data collected by the Cyberwatch Add-on:
vulnerability posture, prioritisation, compliance, estate inventory and
collection health.

Requires the Cyberwatch Add-on. This app reads what the add-on
writes; it collects nothing itself.

ONE THING TO CONFIGURE. Edit the search macro cyberwatch_index so that it names
the index the add-on writes to, under Settings > Advanced search > Search
macros. Nothing in this app works until that is done, and nothing else needs
doing.

Full documentation, including how the searches reconstruct current state,
is in README.md in this directory, and on the Splunkbase page of the app.
