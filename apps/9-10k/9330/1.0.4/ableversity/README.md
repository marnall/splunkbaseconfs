# Ableversity Splunk Training App

Free Splunk Training & Certification courses with exclusive coupons.

- 12+ expert-led Splunk courses
- Free enrollment for Fundamentals 1
- Exclusive coupon codes
- Certification preparation

## Installation

Download and install via Splunk Web or CLI:

```bash
splunk install app ableversity-1.0.2.spl
```
