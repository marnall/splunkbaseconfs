A) Python libraries under lib/ (licensing subsystem)
   All are pure Python — no compiled .so/.pyc is shipped.

   - splunklib (Splunk Enterprise SDK for Python) v3.0.0
     Project: https://github.com/splunk/splunk-sdk-python
     License: Apache License 2.0
     Bundled: lib/splunklib/
     (Implements the v2 chunked custom-search-command protocol for
      `| innolicense`, the server-side license gate.)
     MODIFIED: the optional `splunklib/ai/` subpackage was removed. It is not
     used by this app and it depends on libraries we do not bundle (langchain,
     mcp, pydantic, httpx); it is also the sole reason the upstream wheel
     declares Requires-Python >= 3.13. With it removed the remaining modules
     import cleanly on Python 3.9 and 3.13 alike (verified 2026-07-31 on
     Splunk 10.2.2), which is what lets the app keep supporting Splunk 9.x.
     No other file was altered.

   - rsa (v4.9.1)
     Project: https://stuvel.eu/rsa
     License: Apache License 2.0
     Bundled: lib/rsa/
     (Pure-Python RSA used to verify the offline, RSA-SHA256-signed license
      key. Pure Python is required so the app stays AppInspect-clean.)

   - pyasn1 (v0.6.4)
     Project: https://github.com/pyasn1/pyasn1
     License: BSD 2-Clause
     Bundled: lib/pyasn1/
     (Dependency of rsa — ASN.1/PKCS#1 key parsing.)

   - defusedxml (v0.7.1)
     Project: https://github.com/tiran/defusedxml
     License: Python Software Foundation License 2.0
     Bundled: lib/defusedxml/
     (Hardened XML parsing of the modular-input definition read on stdin
      by bin/inno_observability_license_monitor.py.)

2) Splunk Distribution of OpenTelemetry Java (splunk-2.31.1-otel-2.31.1)
   Project: https://github.com/signalfx/splunk-otel-java

Removed components
------------------
1) Splunk App For Kubernetes (MIT, Venkata Hareesh Sanagavarapu)
   11 ported Dashboard Studio views (k8s_overview/nodes/workloads/deployments/
   daemonsets/statefulsets/jobs/hpa/cost_efficiency/trace_analysis/user_guide)
   and 2 dropdown lookup CSVs were bundled from 2026-06-12 to 2026-07-28.
   They were deleted in Phase 2 of the K8s monitoring redesign and replaced by
   our own views (k8s_one_view, k8s_deploy_timeline). **No code derived from
   that app is shipped any more**, so its MIT notice no longer applies here.
   (Kept as a record of what was once distributed.)
