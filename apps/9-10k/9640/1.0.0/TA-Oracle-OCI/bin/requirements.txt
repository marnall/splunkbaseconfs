# Dependencies for bin/oci_stream.py
#
# IMPORTANT — this is the fix for the exact problem that broke the old
# TA (Splunkbase app 5222) on Splunk 9.3+/10: that add-on shipped
# PRE-COMPILED binaries built against Python 3.7. Splunk's embedded
# Python has since moved on, so those binaries fail to load.
#
# Do NOT vendor pre-built wheels/binaries into bin/ and commit them to
# this package. Instead, install fresh, on the target instance, against
# Splunk's *actual* bundled interpreter:
#
#   $SPLUNK_HOME/bin/splunk cmd python3 --version
#   $SPLUNK_HOME/bin/splunk cmd python3 -m pip install --break-system-packages \
#       --target=$SPLUNK_HOME/etc/apps/TA-Oracle-OCI/bin/lib \
#       -r $SPLUNK_HOME/etc/apps/TA-Oracle-OCI/bin/requirements.txt
#
# This compiles/pulls the correct wheel for whatever Python version this
# specific Splunk instance ships, so it stays correct across upgrades —
# just re-run the install step after any major Splunk version bump.
#
# The script adds bin/lib to sys.path automatically if present (see
# oci_stream.py path bootstrap) — no manual PYTHONPATH needed.
