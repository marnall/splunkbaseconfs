# Requirements and optional integrations

**Author:** Eric Cobbs

**Required dependency:** Splunk Enterprise Security 8.x

> **Splunk Enterprise Security 8.x is required. Cyber Defense Command Center is not supported as a standalone Splunk app.**

## Required baseline

- Splunk Enterprise 9.2 or later, or a compatible Splunk Cloud Platform deployment
- Splunk Enterprise Security 8.x
- Splunk Common Information Model
- Read access to configured security, risk, notable, internal, audit, and summary scopes
- Administrator or security-content administrator access for configuration changes

Native ES Content Management, Detection Testing, test_risk, test_notable, and detection versioning remain authoritative for creation, testing, promotion, and rollback.

## Validated development lab

- Splunk Enterprise 10.0.5
- Splunk Enterprise Security 8.5.1
- Splunk Common Information Model 8.5.0
- SA-ContentVersioning 8.5.1
- SA-TestModeControl 8.5.1
