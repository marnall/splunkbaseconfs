# Enterprise Security capability boundary

**Author:** Eric Cobbs

**Required dependency:** Splunk Enterprise Security 8.x

| Native Enterprise Security capability | Removed from CDCC | CDCC extension retained |
|---|---|---|
| Security Posture and Executive Summary | Finding counts, urgency and security-domain summaries | Cross-layer assurance debt and reliability outliers |
| Mission Control and investigation timelines | Finding queue, triage timeline and generic incident reconstruction | Pipeline conversion only; no case-management replacement |
| Risk Analysis | Entity leaderboards, score trends and risk-event exploration | Risk-event data-quality and entity-type consistency |
| Finding Geography | Maps, countries and geographic finding summaries | Removed entirely |
| Unified Threat Intelligence, Indicators and TI Audit | Feed status, IOC inventory, threat findings and download health | Raw threat telemetry-to-finding conversion gaps |
| Analyst Queue Audit and Investigation Overview | Ownership counts, reviewer activity, MTTT and MTTC | SLA breaches, p90 age and queue imbalance |
| Data Source Health, Indexing Audit and Data Model Audit | Index volumes, source freshness and acceleration health | Field completeness, schema exceptions and ingest lag |
| Asset and Identity Investigators | Generic user, host and asset investigation | Removed entirely |
| Content Management | Detection editing, enablement and lifecycle | Runtime reliability, zero-yield candidates and metadata debt |
