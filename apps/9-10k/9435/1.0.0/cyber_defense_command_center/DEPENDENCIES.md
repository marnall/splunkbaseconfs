# Dependencies

**Author:** Eric Cobbs
**Required dependency:** Splunk Enterprise Security 8.x

Cyber Defense Command Center is an extension for Splunk Enterprise Security and is not supported as a standalone Splunk application.

## Required

- Splunk Enterprise 9.2 or later, or a compatible Splunk Cloud Platform deployment
- Splunk Enterprise Security 8.x
- Splunk Common Information Model
- Access to the ES risk and finding data used by the installed dashboards
- A readable `summary` index for detection-assurance assessment state

## Optional

Network Diagram Viz, Event Timeline Viz, and Heat Map Viz may be installed separately for future enhancements. Version 1.0.0 does not require these visualization packages.

## External services

Version 1.0.0 does not make unattended calls to external services, download remote code, or require external API credentials.
