# Release notes

## 1.6.9

Updated app icon, now built from Stormshield's official brand asset, with

## 1.6.8

First public release on Splunkbase. This add-on was developed and
hardened internally at Process-IT — parsing rules, CIM mappings and
packaging were iterated on in-house before this initial submission, which
is why the version number does not start at 1.0.0.

It provides sourcetype classification, field extraction and CIM mapping
for Stormshield firewall syslog data, covering the Network Traffic, Web,
Authentication, Intrusion Detection, Change, Network Sessions/VPN, DHCP
and Vulnerabilities data models. See README.md for the full list of
supported sourcetypes, compatibility, and installation instructions.
