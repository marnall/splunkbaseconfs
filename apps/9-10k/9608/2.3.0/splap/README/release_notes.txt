SPLap 2.3.0 (2026-09-03)
- New (Position Worm): Save image. The whole-race chart with the session title, the race stats and the wordmark as
  a PNG, drawn in the browser, ready to post. Nothing is uploaded anywhere.
- New (Incident Review): "What happened next" under every event lists the later race-control messages that name
  the same cars (noted, under investigation, penalty, penalty served); click one to open it. Same loaded rows,
  no extra search.
- New (Labs): a Monza challenge card for the real session: three questions with deep links into Lap Delta
  (NOR lap 48 vs PIA lap 47), the Position Worm (the lap 45/46 McLaren stops) and Incident Review (lap 42,
  Turn 5), plus a "Send your answer" mail link and a link to splap.dev/monza (both open only when clicked).
- New (Pit Wall): jump to lap from the timeline (laps inside the replay window); deep links ?attract=1 (starts
  Attract Mode once the replay is moving) and ?broadcast=1 (opens in broadcast mode) for kiosk and floor demos.
- New: the Fast Lap Tour has six steps and starts on the Position Worm.
- Changed (About & Support): the header strip shows the bundled real session instead of the synthetic fixture's
  labels. Changed (Connect Data): the import-status panel explains "no imports yet" instead of a generic empty
  message.
- New: an honest rating ask. After real use (a few Show SPL opens across views, three analysis views, a finished
  Fast Lap Tour or a completed import; never on first launch) one small card asks whether SPLap earned a Splunkbase
  rating, with "Report a problem" given equal weight. "Not now" snoozes it for 30 days; it stops after two. The
  answer is remembered in this browser only (localStorage key splap.rate.v1); nothing is sent anywhere and the
  two actions are plain links that open only when clicked.
- New (About & Support): "Rate it, or tell us what is rough" panel with the same two links, always available.
- Changed (About & Support): the disclaimer now describes the packaged real session (OpenF1, non-commercial
  terms) and the synthetic fixture accurately; the Data provenance panel shows the Monza session (provider,
  telemetry window, row counts) as well as the synthetic manifest.
- Changed (Install Doctor): the optional OpenF1 connectivity check no longer runs by itself when the page opens;
  it reports SKIP with a TEST button (or runs with ?probe=1). The app now makes no external request on its own,
  and an air-gapped install no longer waits 6 s for a timeout or reports a warning it cannot fix.
- Changed (Fast Lap Tour): the incident and lap-comparison steps now open the real 2025 Italian GP session
  (a race-control incident; NOR lap 48 against PIA lap 47) instead of synthetic Demo Race 07 parameters.
- Changed: README/privacy.txt, README/support.txt and NOTICE no longer carry stale version numbers and list
  every outbound link and request precisely.
- No changes to data, searches, dashboards, tokens, sourcetypes, imports or the canonical schema.

SPLap 2.2.0 (2026-08-28)
- New: Position Worm - the whole race on one chart. Lap-by-lap position for every driver from observed position
  and lap events (one bounded search, zero per interaction); pit stops dotted, SC/VSC/red-flag periods shaded,
  the raw-telemetry span highlighted; clicking inside it opens the Pit Wall replay at that moment with the
  involved driver selected. Winner / laps led / biggest climb / pit stop stats. Show SPL as everywhere else.
- New (Pit Wall): Attract Mode - a sit-back autopilot that plays the replay and hops to the next pit stop,
  overtake or flag every ~18 seconds, selecting the involved driver. Any click or key hands control back.
  Uses the already-loaded event lists; no searches.
- New (Connect Data): one-click featured races - the Grand Prix list of the selected season is rendered as
  chips; one click jumps straight to the race weekend's Race session and its capability preview. Everything
  downstream is the normal wizard, so the idempotence check and estimate still run.

SPLap 2.1.1 (2026-08-26)
- New: Lap Delta compares two real laps of the selected session (any driver, any complete lap inside the telemetry
  window) aligned by distance from GPS projected onto the derived centreline; per-corner braking point, minimum
  speed, throttle reapplication, entry/exit speed and corner time; 90 m-smoothed cumulative delta.
- New: Incident Review opens a 30 s evidence window on real race-control messages, overtakes, pit stops and team
  radio: circuit map at the cursor, raw telemetry of the involved car(s) (car numbers are parsed from race-control
  text such as "CARS 55 (SAI) AND 87 (BEA)"), positions/gaps/tyres, nearby race control and weather, deep link,
  "Open in Pit Wall at this moment".
- New: shared session picker (packaged + imported sessions) on Lap Delta and Incident Review; the header shows the
  selected Grand Prix and session on every screen.
- New (Pit Wall): lap counter with total laps (e.g. 41/53), tyre-compound and symbol legend under the timing tower,
  live air/track temperature and rain in the venue plate, team-radio markers on the timeline, SHARE MOMENT button
  that copies a link to the exact time, driver, layer and speed.
- Changed: the synthetic Lap Delta and Incident Review moved to lap_delta_synthetic / incident_review_synthetic.

SPLap 2.1.0 (2026-08-26)
- New: Pit Wall replays a real session - 2025 Italian Grand Prix, Monza (OpenF1 session 9912), race window
  14:00-14:13:30 UTC - on a circuit map derived from the cars' GPS: pit lane as its own road, curbs, start/finish,
  sectors, DRS zones, numbered corners, venue plate. Top-down car glyphs (26-32 px) in team liveries with
  collision-aware acronym+number labels, hover card, driver card (gap AND interval, tyre, pit, last/best lap,
  provenance chips), timing tower, replay 0.25x-4x with jump-to pit/overtake/flag, layers, broadcast mode.
- New: Race Engineer deterministic findings (rule id + version, confidence, provenance, evidence, SPL, focus):
  pit-loss anomaly, undercut/overcut, tyre degradation change, pace drop in traffic, sector dominance, battle
  closing rate, SC/VSC strategic impact (modeled), telemetry anomaly, braking-point change, throttle instability.
- New: canonical schema splap.canonical/1 with provenance on every event, per-session capability object and an
  idempotent import_id; one index (default splap) with 17 splap:* sourcetypes and props.conf timestamping.
- New: Connect Data import wizard (season > GP > session > capability preview > profile/window/estimate > index
  check/create > import with progress/retry/cancel > verify > open). Writes through the user's own Splunk session
  (receivers/stream); no HEC token or credential in the browser. Re-import of an existing import_id is refused.
- New: offline race bundle (manifest, session, drivers, NDJSON event files, replay frames, track GeoJSON, palettes,
  ATTRIBUTION, SHA-256 checksums) loadable from the browser or the CLI; tools/splap_import.py CLI with OpenF1
  (primary), Jolpica metadata and optional FastF1 adapters; validation report.
- New: Install Doctor checks for the session registry, real-session lookups, palettes, default index and
  sourcetypes, importer write capability, provider connectivity (optional), offline readiness, cache.
- Changed: the synthetic Demo Race 07 fixture moved to "Pit Wall (synthetic test fixture)", explicitly labelled;
  Lap Delta, Incident Review, Strategy Lab, SPL Garage and Labs still run on that fixture.
- Fixed: SplunkJS SearchManager double "search" prefix (searches starting with "search " matched nothing);
  result paging beyond 1000 rows; CSRF header on importer REST calls.
Known limitations: see docs/RELEASE_EVIDENCE.md in the source repository.
