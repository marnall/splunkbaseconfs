SPLap privacy statement

- SPLap collects no usage analytics and sends no telemetry to Federal AI or anyone else.
- The dashboards make no network requests to hosts other than the Splunk server that serves them.
- Two user-initiated features can reach one external host, api.openf1.org: the optional historical-race
  import in Connect Data, and the "Provider connectivity (optional)" check on the Install Doctor page,
  which only runs when you press its TEST button (or open the page with ?probe=1) and is reported as a
  warning (never a failure) when the host is unreachable, for example on an air-gapped Splunk.
- Outbound links (the Splunkbase listing, the support mailto, the Federal AI site on About & Support)
  open only when you click them.
- Browser localStorage is used only for local conveniences (tour completion, selected driver, replay
  speed, session picker, last Connect Data validation summary, and the rating-ask state under
  splap.rate.v1: page opens, views visited, Show SPL count, your Rate / Report / Not now answer).
  Nothing is synchronised or transmitted; clearing site data resets it.
- The Install Doctor diagnostic bundle is generated in the browser, redacts tokens, passwords, session
  keys and the server GUID, and is copied or downloaded only when you press Copy or Download.
- Connect Data parses files entirely in the browser; no file is uploaded to Splunk by SPLap.
Any future telemetry would be explicit, opt-in, documented, and separable from app functionality.
